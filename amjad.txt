Task 1 — Unification

1.  ?- house = house. true. % Identical constants, so they unify.

2.  ?- house = abc. false. % Two different constants, so they cannot
    unify.

3.  ?- edge(a,b) = edge(C,b). C = a. % C can match the value a, so they
    unify.

4.  ?- edge(a,d) = edge(C,B). C = a, B = d. % C and B can match the
    values a and d, so they unify.

5.  ?- edge(C,B) = edge(a,d). C = a, B = d. % C and B can match the
    values a and d, so they unify.

6.  ?- edge(A,f(g,h)) = edge(a,B). A = a, B = f(g,h). % A and B can take
    the corresponding values, so they unify.

7.  ?- edge(A,A) = edge(b,c). false. % A cannot take two distinct
    constants, so they cannot unify.

8.  ?- edge(A,A) = edge(b,b). A = b. % A can take the same constant b in
    both places, so they unify.

9.  ?- A = B, B = f. A = B, B = f. % A and B are linked, so both can
    take the value f.

10. ?- A = B, B = f, A = e. false. % A and B are linked, so A cannot be
    both f and e.
